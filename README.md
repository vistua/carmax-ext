# CarMax Auctions Scraper — Chrome Extension

Chrome-расширение для сбора данных об автомобилях на аукционе [carmaxauctions.com](https://www.carmaxauctions.com).

## Что собирает

| Поле         | Описание                              |
|--------------|---------------------------------------|
| VIN          | 17-значный идентификатор              |
| Год          | Год выпуска                           |
| Марка        | Make (Ford, Toyota, …)                |
| Модель       | Model                                 |
| Комплектация | Trim                                  |
| Пробег       | Mileage / Odometer                    |
| Цена / Ставка| Стартовая ставка или текущая цена     |
| Дата аукциона| Когда играется лот                    |
| Местоположение | Площадка / Lane                    |
| Состояние    | Condition / Grade                     |
| Цвет         | Exterior color                        |
| Ссылка       | Прямая ссылка на лот                  |

## Установка (Developer mode)

1. Откройте `chrome://extensions/`
2. Включите **Developer mode** (переключатель справа вверху)
3. Нажмите **Load unpacked** → укажите папку с расширением
4. Иконка появится в панели Chrome

## Использование

1. Войдите на [carmaxauctions.com](https://www.carmaxauctions.com) под своим дилерским аккаунтом
2. Откройте страницу со списком аукционов / лотов
3. Нажмите на иконку расширения → **Собрать данные**
4. Для автоматического перелистывания страниц — **Все страницы**
5. Экспортируйте результаты в **CSV** или **JSON**

## Архитектура

```
manifest.json   — Манифест Chrome Extension MV3
content.js      — Скрипт на странице (парсинг DOM + JSON-LD)
background.js   — Service Worker (хранение, CSV-экспорт)
popup.html/css  — Интерфейс расширения
popup.js        — Логика попапа
icons/          — PNG иконки 16/48/128px
```

## Стратегии парсинга

Расширение использует несколько подходов (в порядке приоритета):

1. **JSON-LD** — структурированные данные `<script type="application/ld+json">`
2. **Window state** — `window.__INITIAL_STATE__` или аналоги (React/Next.js)
3. **DOM selectors** — CSS-классы с паттернами `vehicle-card`, `auction-item`, и т.д.
4. **VIN regex** — поиск 17-значного VIN в тексте карточки

## Troubleshooting

**«Карточки не найдены»** — CarMax Auctions активно обновляет сайт. Если стандартные
селекторы не сработали, откройте DevTools (`F12`), найдите CSS-класс контейнера с машиной
и добавьте его в список `SELECTORS.vehicleCard` в `content.js`.

**Требуется авторизация** — расширение работает только после входа в систему.
Сначала войдите как дилер, затем запустите сбор данных.
